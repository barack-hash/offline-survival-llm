# Offline Knowledge Library — Document Checklist

How to use this: for each item, mark it gathered once the actual text file
(.txt or .pdf) is sitting in your `corpus/` folder. "PD" = public domain,
safe to download directly. "OWN" = copyrighted; buy a physical/legal digital
copy and OCR/scan it yourself for personal use — don't download pirated
copies. "FREE" = freely distributed by the publisher for personal/humanitarian
use, but not public domain (check the license before wide redistribution).

## Non-corpus documents worth keeping alongside the project
These aren't for the device's library, but you'll want them as you build:

- [ ] **Bill of Materials (BOM)** — running list of every part bought, cost, and source link
- [ ] **Wiring diagrams** — keypad pinout, display connections, power HAT connections (hand-drawn is fine)
- [ ] **Build log** — dated notes on what you tried, what worked, what didn't (this becomes genuinely valuable once you're troubleshooting months from now)
- [ ] **verify.py test question list** — growing over time, as discussed earlier
- [ ] **Corpus source log** — which document came from where, what edition/date, so you can judge reliability later
